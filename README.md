# 📘 Caderno Temático — Olivia Rodrigo

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como desafio prático da DIO utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O tema escolhido foi a trajetória artística da cantora Olivia Rodrigo, abordando sua carreira, discografia, estilo musical, impacto cultural e repercussão midiática.

---

# 🎯 Objetivos de Estudo

- Conhecer a trajetória da artista;
- Entender a evolução dos álbuns e músicas;
- Analisar temas recorrentes nas letras;
- Explorar o impacto cultural e midiático da cantora;
- Utilizar IA como apoio para estudos e organização de informações.
